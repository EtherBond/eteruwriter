# 醚键打字机（eteruwriter）

把文字逐个字符输入到当前获得焦点的 Windows 程序中。

## 使用方法

1. 双击 `eteruwriter.exe` 打开软件。
2. 将文字输入或粘贴到窗口的文本框中。
3. 设置字符间隔，范围为 **10–2000 毫秒**，默认 **80 毫秒**。间隔越短，输入越快。
4. 可勾选 **窗口置顶**，让工具窗口始终显示在其他窗口前面。
5. 点击窗口顶部的 **开始输入（3 秒后）**，并在倒计时结束前切换到目标输入框。
6. 输入过程中按 **Ctrl + Alt + F12** 可立即停止。停止快捷键提示显示在窗口上方。

## 输入说明

- 多行文本中的换行会作为 Enter 键输入。
- 输入由 Windows 键盘事件完成；目标程序需要接受这类键盘输入。
- 如果开始按钮不可用，表示停止快捷键注册失败。关闭占用 `Ctrl + Alt + F12` 的程序后重新打开本工具。
